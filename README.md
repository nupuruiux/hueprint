# Hueprint

Any image → an accessible UI theme you can ship: colour roles, light and dark modes, and contrast-checked tokens, exported to CSS or Tailwind.

See [`docs/BRIEF.md`](docs/BRIEF.md) for scope and roadmap.

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in values as milestones need them
npm run dev
```

Then open http://localhost:3000.

## Stack

Next.js (App Router) + TypeScript · Tailwind CSS · node-vibrant · culori · Supabase · Vercel
